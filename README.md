
# Примитивная база данных

Учебный проект на Python.

Программа позволяет создавать таблицы и работать с данными через терминал. Данные хранятся в JSON-файлах.

## Установка и запуск

Установка зависимостей:

```bash
uv sync
```

Запуск программы:

```bash
uv run database
```

Сборка пакета:

```bash
uv build
```

## Управление таблицами

Создать таблицу:

```text
create_table users name:str age:int active:bool
```

Показать таблицы:

```text
list_tables
```

Удалить таблицу:

```text
drop_table users
```

Поддерживаются типы int, str, bool. Поле ID добавляется автоматически.

## CRUD-операции

Добавить запись:

```text
insert into users values ("Anna", 20, true)
```

Показать записи:

```text
select from users
```

Найти запись:

```text
select from users where age = 20
```

Изменить запись:

```text
update users set age = 21 where name = "Anna"
```

Удалить запись:

```text
delete from users where name = "Anna"
```

Информация о таблице:

```text
info users
```

Команда help показывает справку, exit завершает программу.

## Дополнительные возможности

- Обработка ошибок через декоратор.
- Подтверждение удаления таблиц и записей.
- Измерение времени выполнения функций.
- Кэширование результатов поиска.

## Хранение данных

Информация о таблицах сохраняется в db_meta.json.

Записи находятся в папке data/ в JSON-файлах.
