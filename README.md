# Примитивная база данных

Учебный проект на Python.

В этом проекте будет реализована простая консольная база данных. Программа будет позволять создавать таблицы, удалять их и работать с записями.

Пока реализован только запуск программы.

## Установка

Для установки зависимостей используется команда:

`uv sync`

## Запуск

Для запуска программы:

`uv run project`

Сейчас программа выводит сообщение:

`DB project is running!`
