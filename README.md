
# Примитивная база данных

Учебный проект на Python.

Программа позволяет создавать таблицы и работать с записями через терминал. Данные сохраняются в JSON-файлах.

## Установка и запуск

Для установки зависимостей:

```bash
uv sync
```

Запуск базы данных:

```bash
uv run database
```

Сборка пакета:

```bash
uv build
```

После сборки можно установить пакет и запускать его командой `database`.

## Управление таблицами

Создать таблицу:

```text
create_table users name:str age:int active:bool
```

Посмотреть таблицы:

```text
list_tables
```

Удалить таблицу:

```text
drop_table users
```

Поддерживаемые типы данных: `int`, `str`, `bool`.

Столбец `ID` создаётся автоматически.

## CRUD-операции

Добавить запись:

```text
insert into users values ("Anna", 20, true)
```

Посмотреть все записи:

```text
select from users
```

Найти запись:

```text
select from users where age = 20
```

Изменить запись:

```text
update users set age = 21 where name = "Anna"
```

Удалить запись:

```text
delete from users where name = "Anna"
```

Информация о таблице:

```text
info users
```

Команда `help` показывает справку, а `exit` завершает программу.

## Дополнительные возможности

- Проверка типов данных.
- Обработка ошибок через декоратор.
- Подтверждение удаления записей и таблиц.
- Измерение времени выполнения функций.
- Кэширование результатов поиска.

## Структура проекта

- `main.py` — запуск программы.
- `engine.py` — команды и основной цикл.
- `core.py` — работа с таблицами и записями.
- `parser.py` — разбор команд.
- `utils.py` — сохранение и загрузка JSON.
- `decorators.py` — декораторы и кэширование.
- `constants.py` — константы.

## Хранение данных

Информация о таблицах хранится в `db_meta.json`.

Записи сохраняются в папке `data/` в отдельных JSON-файлах.

## Проверка проекта

Проверка стиля:


Сборка:

```bash
uv build
```
