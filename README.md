
# Примитивная база данных

Учебный проект на Python.

Программа позволяет создавать таблицы и работать с записями через терминал. Данные сохраняются в JSON-файлах.

## Установка и запуск

Установить зависимости:

```bash
uv sync
```

Запустить программу:

```bash
uv run database
```

Собрать пакет:

```bash
uv build
```

После установки пакета программу можно запускать командой `database`.

## Работа с таблицами

Создать таблицу:

```text
create_table users name:str age:int active:bool
```

Показать таблицы:

```text
list_tables
```

Удалить таблицу:

```text
drop_table users
```

Поддерживаются типы `int`, `str` и `bool`. Поле `ID` добавляется автоматически.

## Работа с записями

Добавить запись:

```text
insert into users values ("Anna", 20, true)
```

Показать все записи:

```text
select from users
```

Найти запись:

```text
select from users where age = 20
```

Изменить запись:

```text
update users set age = 21 where name = "Anna"
```

Удалить запись:

```text
delete from users where name = "Anna"
```

Информация о таблице:

```text
info users
```

Команда `help` показывает справку, `exit` завершает программу.

## Дополнительные возможности

- Обработка ошибок с помощью декоратора.
- Подтверждение удаления таблиц и записей.
- Измерение времени выполнения функций.
- Кэширование результатов поиска.

## Хранение данных

Информация о таблицах хранится в файле `db_meta.json`.

Записи сохраняются в папке `data/` в отдельных JSON-файлах.
