
# Примитивная база данных

Учебный проект на Python.

Программа позволяет создавать таблицы и работать с записями через терминал. Данные сохраняются в JSON-файлах.

## Установка и запуск

Установить зависимости:

```bash
uv sync
```

Запустить программу:

```bash
uv run database
```

Собрать пакет:

```bash
uv build
```

После установки пакета программу можно запускать командой `database`.

## Управление таблицами

Создать таблицу:

```text
create_table users name:str age:int active:bool
```

Показать таблицы:

```text
list_tables
```

Удалить таблицу:

```text
drop_table users
```

Поддерживаются типы `int`, `str` и `bool`.

Столбец `ID` добавляется автоматически.

## CRUD-операции

Добавить запись:

```text
insert into users values ("Anna", 20, true)
```

Показать все записи:

```text
select from users
```

Найти запись:

```text
select from users where age = 20
```

Изменить запись:

```text
update users set age = 21 where name = "Anna"
```

Удалить запись:

```text
delete from users where name = "Anna"
```

Информация о таблице:

```text
info users
```

Команда `help` показывает справку, а `exit` завершает программу.

## Дополнительные возможности

- Проверка типов данных.
- Обработка ошибок с помощью декоратора.
- Подтверждение удаления таблиц и записей.
- Измерение времени выполнения функций.
- Кэширование результатов поиска.

## Структура проекта

- `main.py` — запуск программы.
- `engine.py` — обработка команд.
- `core.py` — работа с таблицами и записями.
- `parser.py` — разбор команд.
- `utils.py` — работа с JSON-файлами.
- `decorators.py` — декораторы и кэширование.
- `constants.py` — константы.

## Хранение данных

Метаданные таблиц хранятся в файле `db_meta.json`.

Записи сохраняются в папке `data/`.

## Проверка проекта

Проверка кода:

```bash
uv run ruff check .
```

Сборка пакета:

```bash
uv build
```

Проверка пакета:

```bash
uvx twine check dist/*
```
